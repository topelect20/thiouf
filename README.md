# THIOUF

Site du restaurant **THIOUF**, grillades de la Petite Côte à Nguékhokh.

Poisson au feu de bois, thieboudienne, terrasse ouverte. La réservation part sur WhatsApp.

## Voir le site

Ouvrez `index.html`, ou la page GitHub Pages du dépôt.

Le numéro affiché (`+221 77 555 01 90`) est un placeholder. Remplacez-le dans `index.html` et `app.js` (`221775550190`) par le WhatsApp du restaurant.

## Contenu

- `index.html`, `styles.css`, `app.js` — le site
- `images/` — photos de la carte et de la terrasse
- `source/` — version React utilisée pour l’aperçu

Les prix sont indicatifs, en francs CFA.
